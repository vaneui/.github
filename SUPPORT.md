# Getting help with VaneUI

- **Documentation:** [vaneui.com/docs](https://vaneui.com/docs) has a page for every component, the setup guides and the props reference.
- **Try a snippet:** the [playground](https://vaneui.com/playground) runs VaneUI code in the browser.
- **AI assistants:** [llms.txt](https://vaneui.com/llms.txt) and the `@vaneui/mcp` server give a coding assistant the same docs. See [AI Assistants](https://vaneui.com/docs/getting-started/ai-assistants).
- **A bug or a missing feature:** open an issue in the repository of the package. [Contributing](https://github.com/vaneui/.github/blob/main/CONTRIBUTING.md) lists them.
- **A security problem:** follow the [security policy](https://github.com/vaneui/.github/blob/main/SECURITY.md).
- **Anything else:** hello@vaneui.com.
